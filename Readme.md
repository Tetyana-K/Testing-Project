
# Stub, Fake, Spy, Dummy, Mock

Test Doubles (тестові замінники) — це узагальнена назва об'єктів, які використовуються під час тестування 
замість реальних залежностей програми.
Їхня основна мета — ізолювати клас, який ми тестуємо, від інших компонентів системи,
щоб перевірити його роботу незалежно від бази даних, API, файлової системи чи інших сервісів.

> Stub, Fake, Spy, Dummy належать до категорії **Test Doubles** — тестових замінників реальних об'єктів, 
> які використовуються під час тестування.

Основні види Test Doubles
Є п'ять поширених різновидів:
1. Dummy — порожній об'єкт
Потрібен лише для передачі в метод або конструктор. У тесті фактично не використовується.

2. Stub — заглушка
Повертає заздалегідь визначені дані, щоб ми могли перевірити поведінку тестованого класу.

3. Fake — спрощена реалізація
Має робочу, але спрощену реалізацію. Наприклад, замість справжньої бази даних використовує колекцію в пам'яті.

4. Spy — об'єкт-спостерігач
Записує, як саме з ним взаємодіяли: скільки разів викликали метод, з якими параметрами тощо.

5. Mock — об'єкт із перевіркою очікуваної взаємодії
Дозволяє налаштувати поведінку залежності та перевірити, чи тестований клас викликав її потрібним способом.

Stub — заглушка
Stub — це тестовий об'єкт, який повертає заздалегідь визначені результати у відповідь на виклики методів.

Його основне завдання — надати тестованому класу потрібні дані, щоб ми могли перевірити його логіку.


Головна ідея - 
 Stub контролює дані, які отримує тестований клас


 Spy — об'єкт-спостерігач
Spy — це тестовий об'єкт, який записує інформацію про те, як його використовували.

Наприклад:
- скільки разів викликався метод;
- які параметри йому передавалися;
- у якій послідовності відбувалися виклики.
На відміну від Stub, Spy нас цікавить не тільки результат, який повертає залежність, а й сам факт взаємодії з нею.

Dummy
Мені просто потрібен об'єкт.
Заповнює місце.

Stub
Дай мені конкретну відповідь.
Повертає задані дані.

Fake
Працюй, але спрощено.
Має власну реалізацію.

Spy
Запам'ятовуй, що відбувається.
